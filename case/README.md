# Case

Pasta reservada para a case personalizada do NAS: modelos 3D, medidas e documentação de montagem.

## Situação

- O Raspberry Pi 5 roda hoje na **case oficial, sem ventoinha** (o FAN header está danificado). Temperatura em repouso: ~63 °C.
- O projeto da case 3D começa depois da escolha do hardware de armazenamento, que define dimensões, alimentação e fluxo de ar.

## Requisitos

- refrigeração passiva do Raspberry Pi (dissipador ou case de alumínio);
- acesso fácil aos discos;
- fluxo de ar adequado para os discos escolhidos;
- passagem organizada dos cabos USB, de rede e de alimentação;
- acesso ao slot do microSD (sistema e recuperação);
- baixo ruído e dimensões compactas.
